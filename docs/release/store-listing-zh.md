# 应用商店资料草稿

## 应用名称

自动记账

## 一句话简介

读取支付和银行通知，在本机自动生成收支账单。

## 详细介绍

自动记账是一款简单的 Android 本地记账工具。开启通知读取权限后，应用会识别支付宝、微信、银行等通知中的金额和收支方向，并自动保存为本地账单。用户可以查看收入、支出和结余汇总，也可以手动编辑或删除识别结果。

当前版本专注于本地自动记账：

- 通知读取识别收支
- 本地保存账单
- 自动去重
- 收入、支出、结余汇总
- 账单编辑和删除
- 不需要账号登录
- 不上传财务数据

## 关键词建议

记账, 自动记账, 通知识别, 收支记录, 本地账本, 支付通知, 账单

## 权限说明

### 通知读取权限

用于读取支付、收款、银行到账等通知文本，并在本机识别金额和收支方向。应用不会将通知内容上传到服务器。

## 测试账号

无需测试账号。

## 分类建议

财务 / 工具

## 内容分级说明

不包含用户生成公开内容，不包含社交、购物、博彩或成人内容。
