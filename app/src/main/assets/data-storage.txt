账本和文件存在哪里

1. 账目与预算

账目、分类、备注和月预算保存在本机的应用私有数据库中。
当前数据库位置：
{{DATABASE_PATH}}

这是系统管理的私有目录，普通文件管理器通常无法直接打开。正常卸载应用或在系统设置中清除应用数据，会删除这些账本数据。卸载前请先到「设置 → 导出 JSON 备份」保存账本。

2. 设置与缓存

API 密钥、统计偏好、动账提醒开关与来源选择等设置保存在应用私有目录的 shared_prefs 中；运行缓存位于 cache 和 code_cache 中。
当前应用数据目录：
{{DATA_PATH}}

这些文件正常卸载时会一起清除。应用没有自行创建公共存储目录。开启动账提醒并授予通知访问权限后，由系统绑定通知监听服务，同时运行显示持续通知的前台常驻服务，退出界面后继续监听。持续通知提供停止操作；关闭应用内监听开关也会停止采集和常驻服务。手机启动并解锁、覆盖升级后会按原开关尝试恢复；系统强行停止、厂商后台清理或撤销通知访问权限可能中断监听。通知访问权限可在系统设置中撤销。

动账提醒候选及识别记录也存于上述私有数据库，通知只在本地处理。验证码提醒会跳过，长数字会遮蔽，通知内容仅保存截取后的识别依据。可在「设置 → 待确认账单 / 识别记录 → 清理记录」清理，正式账目会保留。清理会移除去重依据；卸载或清除应用数据也会移除记录。

3. 手动导出的账本备份

JSON 备份包含正式账目、预算与分类，不包含待确认提醒、识别记录和通知授权设置。换机后需要重新授权。

备份文件名默认是 own-ledger-日期.json。保存位置由你在系统文件选择器中决定，可能是「下载」、其他文件夹或网盘；应用没有固定的备份目录。

查找时，请打开保存时使用的文件管理器或网盘，搜索 own-ledger- 或 .json。导入不会删除或移动原备份。

卸载应用不会自动删除备份。备份为明文，包含账目和备注等信息；不再需要时，请在保存位置自行删除，并按需要清理该位置的回收站。

4. APK 安装包

通过浏览器、微信、QQ 或网盘收到的 APK，保存在下载时选择的位置或对应应用管理的位置。有钱日记不会另存安装包，也无法确定它的具体路径。

卸载有钱日记不会自动删除这些下载文件。可在文件管理器或接收文件的应用中，搜索 youqian-diary 或 .apk 后自行清理。

5. 系统备份与卸载说明

当前版本关闭 Android 自动备份，并配置排除账本、设置和文件的云备份及设备迁移。手机厂商或第三方备份工具另外保存的副本，需要到相应工具中管理。

以上清除行为指正常卸载。系统的应用归档、保留数据卸载或第三方备份不等同于正常卸载。应用不会在卸载时主动删除你导出的备份或下载的安装包。
